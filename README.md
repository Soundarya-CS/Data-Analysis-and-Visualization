**YouTube Trending Video Analysis**

This project analyzes the top trending videos on YouTube using the **YouTube API** and **pandas**.

**Features:**
- Fetches **top 10 trending videos** in a selected region.
- Analyzes **views, likes, and comments correlation**.
- Uses **Matplotlib & Seaborn** for data visualization.

**Technologies Used:**
- Python 🐍
- Google API Client
- Pandas & Seaborn
- Matplotlib

**How to Use:**
1. Clone this repository.
2. Install dependencies using `pip install -r requirements.txt`.
3. Run `python Youtube_API_DataAnalysis.py`.
